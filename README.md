## 玩法（手机竖版，单手）

星空手机壳里开着一家像素麦当劳：顶部是金币余额和「欢迎光临」，中间是实时营业的门店
（菜单板、开放式后厨、柜台、坐满顾客的餐厅），底部是小麦的对话气泡 + 三个大彩按钮 + 金色主按钮。

1. **开场三选一**：省钱套餐 / 轻松吃 / 尝新品（也可以直接点「开始点餐」走完整问答）
2. **问答点单**：几个人 / 忌口（可多选）
3. **AI 配餐**：主推 + 省钱版 + 丰盛版三套方案，每套有真实总价、人均、热量和推荐理由
4. **真实下单**：MCP 下单，拿到真实取餐号；下单金币会真的扣掉
5. **像素后厨**：小人接单、煎制（冒烟动画）、打包，顾客会走到取餐口等餐，递给你**真实号码牌**
6. **用餐评价**：星级 → 进入麦门评价墙

## 本地运行

```bash
node server/server.js          # 默认 3000 端口，demo 模式（无需 Token）
# 浏览器打开 http://localhost:3000
```

接真实麦当劳 MCP：

```bash
MCP_MODE=live MCP_ENDPOINT=<MCP端点> MCP_TOKEN=<你的token> node server/server.js
```

## 技术栈

- 纯 Node.js 后端（零依赖），单端口托管静态页面 + REST API
- MCP 适配层收敛在 `server/mcp.js` 一个文件，demo/live 双模式无缝切换
- 前端 Canvas 像素场景 + 状态机流程，无需任何前端框架

## 像素场景与角色素材

上半屏场景在 `web/scene.js`，一套 2.5D 像素门店：墙面（金色拱门招牌 / 四格菜单板 / 取餐台指示）、
开放式后厨（抽油烟机 / 煎台 / 炸炉 / 保温柜 / 饮料机 / 出餐屏）、柜台、客座餐厅。

- **四个小人随机分配「店员 / 顾客」**：每次刷新重新抽签（小麦固定是店员，另外 3 个里抽 1 名店员 + 2 名顾客），
  顾客会自己进门、找座、等餐、去取餐口拿号、开吃、离店，循环往复
- **各有任务，不同时干活**：接到单只随机点名一名厨师 + 一名打包员，其余店员照样在后厨溜达摸鱼；
  顾客也各按各的节律进出，不会全体一起动
- **素材管线**：`tools/staff-source.png`（4 角色 × 4 朝向的白底大图）→ `python3 tools/build-sprites.py` →
  `web/assets/staff.png`（4 列角色 × 4 行朝向，单格 37×51）。脚本做的是「边缘洪水填充去白底 → 连通域切图 →
  整数倍缩到 44px 高 → 底部对齐进图集」，零第三方依赖（PNG 编解码在 `tools/pngtool.py` 里，纯标准库）。
- **改作息 / 站位 / 抽签规则**：只改 `web/scene.js` 里的 `assignPeople()` 和 `onStatus()`。
- **调试**：`http://localhost:3000/?state=preparing` 可强行把场景切到 idle / placed / preparing / ready / dining 任一状态，不用真下单。
- **演示节奏**：demo 模式默认 36 秒出餐，现场想更快/更慢用 `DEMO_READY_SECONDS=20` 调。
